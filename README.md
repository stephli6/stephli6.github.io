# Stephanie Hwang — Data Analyst Portfolio

Personal portfolio website for **Stephanie Hwang**, Data & BI Analyst
(UCLA MEng, Data Science, June 2027; UC Irvine B.S. Applied Mathematics,
Data Science Concentration, 2026).

**Live site:** https://stephli6.github.io

## What's on it

- **Home** — about, and an experience timeline
- **Projects** — three end-to-end analytics projects, each from raw data to a
  result a business can use, with code and methods linked:
  - E-commerce Revenue & Customer Analytics (Google Merchandise Store GA4
    sample: $362,165 revenue, 5,692 events, 3.68% funnel conversion)
  - Amazon Operational Strategy & People Analytics Externship (in progress)
  - Tata Data Visualisation Job Simulation (Forage)
- **Skills** — SQL, Python, Tableau, Power BI, Excel, BigQuery, Looker Studio,
  DuckDB, GA4, Git/GitHub
- **Resume** — one-page PDF, linked from the hero button

## Run it locally

```bash
npm install
npm start
```

## Deploy

```bash
npm run deploy
```

Builds the site and publishes `build/` to the `gh-pages` branch, which
GitHub Pages serves at https://stephli6.github.io.
